# Changelog

## 1.0.0

- First release: a Controls row in the Options menu (or Ctrl + F5 from the main menu) opens a Controls screen in the game's own style for rebinding keyboard and controller actions. You can replace, add, restore or unbind keys per action, or reset a whole column. A Mouse section assigns actions to left, right and middle click. A Mods section covers other installed mods' key settings, pairing a keyboard setting with the controller setting for the same action even when the mod has other keys in that section, and marking a controller setting with no keyboard partner as "(Controller)", with warnings when keys clash. Bindings are saved per controller model. The game's button prompts, including the battle Fire and discard buttons, follow your bindings and disappear when an action is unbound, with matching icons drawn for keys the game has no art for.
